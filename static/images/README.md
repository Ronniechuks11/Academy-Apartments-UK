# Image slots — Academy Apartments

| Filename                  | Status      | Where it's used            |
|----------------------------|-------------|------------------------------|
| `hero.png`                 | ✅ Added    | Homepage hero background |
| `apartment-studio.jpg`     | ⬜ Needed   | Studio apartment (set as the "Image filename" on that listing in /admin) |
| `apartment-onebed.jpg`     | ⬜ Needed   | One-bedroom apartment (same — matches the "Image filename" field in /admin) |

Drop new photos into this folder, then go to `/admin/apartments`, edit the
relevant listing, and set "Image filename" to match exactly. Adding a brand
new apartment type later works the same way — upload the photo here first,
then reference its filename when creating the listing in the admin.
